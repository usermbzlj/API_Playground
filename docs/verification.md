# 验证与待验收

## 自动检查

要求 Node.js 24+。完整检查还需要 Python 3.11+ 和 llm-bench 无界面依赖，先运行 `npm run setup:bench`。

```powershell
npm ci
npm run setup:bench
npm run check
npm run format:check
```

`npm run check` 覆盖类型、目录、请求构建、原生适配、凭证导入、Gemini、融合、工作区状态、隔离后端、性能桥接与生产构建。测试使用临时数据库、模拟凭证和本地 HTTP/WS 服务；不会访问私人工作区或执行付费推理。

2026-10-25 的 v0.4.0 完整检查退出 0：12 项核心、24 项原生适配、7 项导入、13 项 Gemini、3 项融合、9 项工作区、57 项隔离后端检查，以及性能桥接回归与保留的 54 项 Python 上游测试；生产构建、格式检查与 `git diff --check` 均退出 0。v0.4.0 新增的 13 个操作只有请求/响应契约测试和文档依据，没有真实 Key 调用，状态仍为 `documented`。检查中修复了压测夹具在 localhost 同时解析 IPv4/IPv6 时的绑定与固定 IP 顺序问题（测试服双栈 + 优先 IPv4 固定），不涉及外部付费调用。

## 主要检查范围

- **工作区连续性**：草稿恢复、敏感字段落盘脱敏、切页后台运行、停止状态、结果绑定发送输入、上传合并与过期工具响应隔离。
- **连接与设置**：配置保存原子性、代理认证保留、密钥修改后缓存失效、无法安全探测时明确返回未验证状态。
- **素材与任务**：持久引用保护、删除历史保留文件、明确选择清理、临时轮询错误退避、产物下载独立重试、重启后继续跟踪。
- **原生适配**：HTTP/SSE 事件、参数开关、思考与工具签名续传、音频编码及素材 MIME；模拟响应不提升厂商实测状态。
- **性能评测**：固定请求/时长/RPS/并发扫描、预算与尝试上限、停止保留部分结果、协议终态、空响应和截断流失败、导入原始来源、历史请求快照审计、JSON/CSV 导出脱敏。
- **本机服务**：旧构建资源缺失返回 404，HTML 禁止陈旧缓存；凭证仅存本机，公开源码不附带私人数据库、连接清单或实验导出。
