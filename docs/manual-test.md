# 亲自上手验收

入口：[能力探索](http://127.0.0.1:8787/#/explore)、[性能评测](http://127.0.0.1:8787/#/bench)。启动命令为 `npm start`；源码修改后的开发模式为 `npm run dev`。

本轮可先进行不产生模型费用的检查：填写输入后切换页面并返回，确认草稿保留；从旧记录载入后修改输入，确认旧结果的标签保持原样并出现未运行提示；上传文件期间继续编辑，确认文字保留；在对比页切换标签后，确认各通道配置仍在。原始请求台可复制 PowerShell/Bash 示例，但无需执行。

素材库可查看文件占用与引用。从实验台选择已有素材后，当前标签页草稿使用中的文件应不可清理。删除一条无需保留的测试历史时，产物仍应在素材库；只在明确选中未引用文件并确认后才删除文件。请勿用真实重要记录验证删除行为。

手机或窄窗口应可直接使用底部运行、停止、结果入口，所有页面不应出现整页横向滚动。真实录音、播放、输入法、网络波动及长时间使用的手感仍需在实际设备确认。应用内切离实时会话应停用麦克风，关闭或刷新网页会中断会话。

1. **找到能力**：切换六条路线、四层模型、已接入账户，搜索一个厂商或玩法，载入预设。核对进入的操作、账户和模型符合选择；目录状态与本机证据各自显示。
2. **跑一个熟悉的文本实验**：沿用已有可用连接，检查原生参数与请求预览，再运行、恢复历史。验证输出、思考、工具、事件和费用显示；没有厂商数据的指标应保持未知。
3. **受控对比**：复制相同输入；只改温度或思考参数，检查条件审计列出真实差异。确认后分别调用，再从分组历史回看。
4. **性能基线**：先用 3–5 个请求、并发 1、输出上限 128、无预热/重试。核对确认快照，运行后查看样本与指标。然后按需尝试低档位扫描；运行中切页再返回、停止、导出 JSON/CSV、导入旧报告和 2–6 条结果对照。
5. **Gemini（有对应账户时）**：添加原生 Gemini 连接，手动核对账号可见模型。按需尝试思考、搜索、JSON 和手动工具续聊；语音单人/双人预设会产生真实调用，核对朗读、风格、声音和 WAV 回放。未用真实 Key 验收的能力仍标为文档依据。
6. **变量模板与移动布局**：原始请求台载入变量模板，填入带引号/换行的 PROMPT，预览应保留正确 JSON。模板预览不发请求。用手机或窄窗口查看图谱、菜单和工作台；核对滚动、触控、录音权限与真实声音体验。
7. **v0.4.0 新增原生操作（有账户时逐项付费验收）**：OpenAI Responses 先跑纯文本，再观察推理摘要、工具请求与 JSON Schema；Anthropic Messages 检查 adaptive thinking 摘要、effort 与缓存命中字段；OpenAI/Gemini/Ark Seedream 图像检查产物落盘与水印；Wan 3.0、Seedance 2.5、MiniMax H3 v2 检查 task_id、状态轮询与 24 小时链接；Tripo 图片到 3D 必须使用公网图片链接；Qwen3-ASR 用 5 分钟内的短音频。新增操作默认 `documented`，没有实测证据时不要改成 `tested`。
8. **线索页与入口标记**：确认“原始请求”和“模型发现”不再显示为未适配线索；其余仍标线索的能力（长上下文、翻译、下一步编辑、预测输出、GUI 操作、深度研究、OCR、声音设计、音乐、视频编辑、路由）不应出现可运行实验入口。

性能评测可能快速累计用量；预热和重试同样可能计费。已发送请求的费用不因本地停止而撤销。对比与压测说明不同统计口径，少量样本不构成厂商排行榜。测试发现问题时保留本机运行/评测 ID、实际操作和可复现输入；分享记录前检查自由文本隐私。
